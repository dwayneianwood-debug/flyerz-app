The two profiles in this folder are from Ghostscript's iccprofiles directory.

  default_cmyk.icc  Artifex CMYK SWOP profile

default_cmyk.icc is the same file already stored as
server/profiles/CoatedFOGRA39.icc. Bundling both profiles lets a Windows
install open them without a Linux colour directory. A Ghostscript
install folder (C:\Program Files\gs\gs*\iccprofiles) is still searched
when these copies are missing.
